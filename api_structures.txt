================================================================================
PawMatch API Data Structures & Frontend Developer Reference
================================================================================
Base URLs:
- Production Base URL: https://pawmatch-8zwt.onrender.com
- Localhost Base URL:  http://localhost:8000

Common API Response Envelope Standards:
All responses (except raw /health/ endpoints) follow a unified standard JSON wrapper:

Success Envelope (2xx):
{
  "success": true,
  "message": "Detailed success message",
  "data": { ... }
}

Error Envelope (4xx / 5xx):
{
  "success": false,
  "message": "Summary error message",
  "errors": {
    "field_name": [
      "Error description detail"
    ]
  }
}

2. AUTHENTICATION & USER ACCOUNTS ENDPOINTS
================================================================================

--------------------------------------------------------------------------------
2.1 Register New User
--------------------------------------------------------------------------------
- Description:    Registers a new inactive user account and sends verification email.
- HTTP Method:    POST
- Authentication: Public (AllowAny)
- Rate Limit:     Throttle protected (RegisterRateThrottle)
- Production URL: https://pawmatch-8zwt.onrender.com/api/v1/accounts/register/
- Localhost URL:  http://localhost:8000/api/v1/accounts/register/

Request Headers:
  Content-Type: application/json

Request Body:
{
  "email": "user@example.com",
  "password": "StrongPassword123!",
  "confirm_password": "StrongPassword123!",
  "first_name": "John",
  "last_name": "Doe"
}

Response (201 Created):
{
  "success": true,
  "message": "Registration successful. Please check your email for your 6-digit verification code.",
  "data": {
    "user": {
      "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
      "email": "user@example.com",
      "first_name": "John",
      "last_name": "Doe",
      "full_name": "John Doe",
      "phone_number": "",
      "profile_image": null,
      "is_email_verified": false
    }
  }
}

Response (400 Bad Request):
{
  "success": false,
  "message": "Validation error message",
  "errors": {
    "email": [
      "A user with this email address already exists."
    ],
    "confirm_password": [
      "Passwords do not match."
    ]
  }
}

2.4 User Login
--------------------------------------------------------------------------------
- Description:    Authenticates email and password, returning JWT tokens & user info.
- HTTP Method:    POST
- Authentication: Public (AllowAny)
- Rate Limit:     Brute-force throttle protected
- Production URL: https://pawmatch-8zwt.onrender.com/api/v1/accounts/login/
- Localhost URL:  http://localhost:8000/api/v1/accounts/login/

Request Headers:
  Content-Type: application/json

Request Body:
{
  "email": "user@example.com",
  "password": "StrongPassword123!"
}

Response (200 OK):
{
  "success": true,
  "message": "Login successful.",
  "data": {
    "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ0b2tlbl90eXBlIjoiYWNjZXNzIiwiZXhwIjoxNz...",
    "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ0b2tlbl90eXBlIjoicmVmcmVzaCIsImV4cCI6MTc...",
    "user": {
      "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
      "email": "user@example.com",
      "first_name": "John",
      "last_name": "Doe",
      "full_name": "John Doe",
      "phone_number": "+1234567890",
      "profile_image": null,
      "is_email_verified": true
    }
  }
}

Frontend Developer Note:
- Store `access` token in memory or Axios auth header.
- Store `refresh` token securely (e.g. HttpOnly cookie or secure storage).
- Include header `Authorization: Bearer <access>` in all authenticated API requests.
