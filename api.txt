================================================================================
PawMatch API Endpoints Documentation
================================================================================
Production Base URL: https://pawmatch-8zwt.onrender.com
Localhost Base URL:  http://localhost:8000

--------------------------------------------------------------------------------
1. HEALTH & SYSTEM ENDPOINTS
--------------------------------------------------------------------------------

[1.1] Root Service Health Check
- Description: Light-weight health probe for cloud load balancers and orchestrators
- Method:      GET, HEAD
- Auth:        Public (AllowAny)
- Production:  https://pawmatch-8zwt.onrender.com/health/
- Localhost:   http://localhost:8000/health/

[1.2] Django Administration Dashboard
- Description: Django admin panel for platform administration
- Method:      GET, POST
- Auth:        Admin / Superuser Session
- Production:  https://pawmatch-8zwt.onrender.com/admin/
- Localhost:   http://localhost:8000/admin/

[1.3] API V1 Core Health Check
- Description: Sub-system core status health check endpoint
- Method:      GET, HEAD
- Auth:        Public (AllowAny)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/core/health/
- Localhost:   http://localhost:8000/api/v1/core/health/

2. AUTHENTICATION & USER MANAGEMENT ENDPOINTS
--------------------------------------------------------------------------------

[2.1] Register New User
- Description: Register a new account and trigger email verification
- Method:      POST
- Auth:        Public (AllowAny)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/accounts/register/
- Localhost:   http://localhost:8000/api/v1/accounts/register/

[2.2] Verify Email
- Description: Verify email address via token (query param for GET, body for POST)
- Method:      GET, POST
- Auth:        Public (AllowAny)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/accounts/verify-email/
- Localhost:   http://localhost:8000/api/v1/accounts/verify-email/

[2.3] Resend Verification Email

- Localhost:   http://localhost:8000/api/v1/accounts/resend-verification/

[2.4] User Login

3. ROLE-BASED ACCESS CONTROL (RBAC) MANAGEMENT ENDPOINTS
--------------------------------------------------------------------------------

[3.1] List Platform Roles
- Description: List all defined roles and their permissions
- Method:      GET
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/roles/
- Localhost:   http://localhost:8000/api/v1/rbac/roles/

[3.2] Role Detail
- Description: Retrieve details for a specific role
- Method:      GET
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/roles/<role_name>/
- Localhost:   http://localhost:8000/api/v1/rbac/roles/<role_name>/

[3.3] Get User Roles
- Description: Query assigned roles for a specific user ID (UUID)
- Method:      GET
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/users/<user_uuid>/roles/
- Localhost:   http://localhost:8000/api/v1/rbac/users/<user_uuid>/roles/

[3.4] Get User Permissions
- Description: Query all permissions assigned to a specific user ID (UUID)
- Method:      GET
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/users/<user_uuid>/permissions/
- Localhost:   http://localhost:8000/api/v1/rbac/users/<user_uuid>/permissions/

[3.5] Assign Role to User
- Description: Assign a role to a specified user
- Method:      POST
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/users/<user_uuid>/assign-role/
- Localhost:   http://localhost:8000/api/v1/rbac/users/<user_uuid>/assign-role/

[3.6] Remove Role from User
- Description: Remove a role from a specified user
- Method:      POST
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/users/<user_uuid>/remove-role/
- Localhost:   http://localhost:8000/api/v1/rbac/users/<user_uuid>/remove-role/

[3.7] Replace User Roles
- Description: Replace all roles of a user with a new set of roles
- Method:      PUT
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/users/<user_uuid>/replace-roles/
- Localhost:   http://localhost:8000/api/v1/rbac/users/<user_uuid>/replace-roles/

[3.8] Clear User Roles
- Description: Remove all roles assigned to a specified user
- Method:      DELETE
- Auth:        IsAuthenticated + IsAdministratorRole
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/rbac/users/<user_uuid>/clear-roles/
- Localhost:   http://localhost:8000/api/v1/rbac/users/<user_uuid>/clear-roles/

4. SHELTER MANAGEMENT ENDPOINTS
--------------------------------------------------------------------------------

[4.1] Register Shelter Organization
- Description: Onboard and register a new shelter organization for the authenticated user
- Method:      POST
- Auth:        IsAuthenticated (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/register/
- Localhost:   http://localhost:8000/api/v1/shelters/register/

[4.2] Current User Shelter Profile
- Description: Retrieve or update authenticated user's shelter organization details
- Method:      GET, PATCH
- Auth:        IsAuthenticated (Bearer Token) / CanManageShelter for PATCH
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/me/
- Localhost:   http://localhost:8000/api/v1/shelters/me/

[4.3] Current Shelter Upload Document
- Description: Upload verification document to current user's shelter (multipart/form-data)
- Method:      POST
- Auth:        IsAuthenticated (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/upload-document/
- Localhost:   http://localhost:8000/api/v1/shelters/upload-document/

[4.4] Current Shelter List Documents
- Description: List uploaded verification documents for current user's shelter
- Method:      GET
- Auth:        IsAuthenticated (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/documents/
- Localhost:   http://localhost:8000/api/v1/shelters/documents/

[4.5] Shelter Dashboard Overview
- Description: Retrieve shelter dashboard metrics, active pet counts, and recent notifications
- Method:      GET
- Auth:        IsAuthenticated (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/dashboard/
- Localhost:   http://localhost:8000/api/v1/shelters/dashboard/

[4.6] List Shelters Catalog
- Description: Retrieve paginated catalog of shelters with searching, filtering, and ordering
- Method:      GET
- Auth:        IsAuthenticated (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/
- Localhost:   http://localhost:8000/api/v1/shelters/
- Note:        Supports ?status=<status>&city=<city>&state=<state>&is_active=<bool>&search=<term>&ordering=<field>&page=<num>

[4.7] Create Shelter Organization
- Description: Onboard a new shelter organization and initialize owner membership
- Method:      POST
- Auth:        IsAuthenticated (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/

[4.9] Update Shelter Profile
- Description: Update shelter profile details
- Method:      PATCH
- Auth:        IsAuthenticated + CanManageShelter (Bearer Token)

- Localhost:   http://localhost:8000/api/v1/shelters/<shelter_uuid>/

[4.10] Submit Shelter Verification
- Description: Submit active shelter verification workflow for review
- Method:      POST
- Auth:        IsAuthenticated + CanManageShelter (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/<shelter_uuid>/verification/submit/
- Localhost:   http://localhost:8000/api/v1/shelters/<shelter_uuid>/verification/submit/

[4.11] Start Verification Review

- Method:      POST

[4.12] Request Verification Information

- Method:      POST
- Auth:        IsAuthenticated + CanReviewVerification (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/<shelter_uuid>/verification/request-information/

[4.13] Approve Shelter Verification
- Description: Approve shelter verification and update operational status to verified
- Method:      POST
- Auth:        IsAuthenticated + CanReviewVerification (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/<shelter_uuid>/verification/approve/

[4.14] Reject Shelter Verification

- Localhost:   http://localhost:8000/api/v1/shelters/<shelter_uuid>/verification/reject/

[4.15] Manage Shelter Verification Documents

[4.16] Remove Shelter Verification Document
- Description: Delete an unapproved shelter verification document by ID
- Method:      DELETE
- Auth:        IsAuthenticated + CanDeleteDocument (Bearer Token)
- Production:  https://pawmatch-8zwt.onrender.com/api/v1/shelters/documents/<document_uuid>/

[4.17] Manage Shelter Members

- Auth:        IsAuthenticated + IsShelterMember (GET) / CanInviteMembers (POST) (Bearer Token)

[4.19] Remove Shelter Member
